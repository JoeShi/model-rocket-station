# Task 1: 视频流模拟功能

## 任务描述
在首页上增加火箭的视频流功能，可以切换2个机位，可以打开或者暂停视频流，通过本机电脑的两路摄像头输入进行模拟。

## 具体要求

### 功能需求
1. **视频流显示**
   - 在首页添加一个新的视频流卡片组件
   - 显示来自摄像头的实时视频流
   - 视频流应该有合适的尺寸和比例

2. **双机位切换**
   - 支持在两个不同的摄像头之间切换
   - 提供切换按钮或选择器
   - 机位1: 主摄像头 (通常是前置摄像头)
   - 机位2: 副摄像头 (通常是后置摄像头，如果可用)

3. **播放控制**
   - 提供播放/暂停按钮
   - 支持开启和关闭视频流
   - 显示当前视频流状态

4. **用户界面**
   - 使用Material Design 3组件保持界面一致性
   - 添加适当的图标和标签
   - 支持中文界面

### 技术实现要求

1. **摄像头访问**
   - 使用 `navigator.mediaDevices.getUserMedia()` API
   - 处理摄像头权限请求
   - 支持多个摄像头设备的枚举和选择

2. **视频元素**
   - 使用HTML5 `<video>` 元素显示视频流
   - 设置适当的视频属性 (autoplay, muted等)
   - 处理视频流的开始和停止

3. **错误处理**
   - 处理摄像头访问被拒绝的情况
   - 处理设备不可用的情况
   - 提供用户友好的错误提示

4. **模块化设计**
   - 创建新的 `VideoStreamManager` 类
   - 将视频流逻辑封装在独立模块中
   - 在 main.ts 中集成新模块

### 文件修改清单

1. **新建文件**
   - `src/modules/videoStream.ts` - 视频流管理模块

2. **修改文件**
   - `index.html` - 添加视频流卡片到首页
   - `src/main.ts` - 集成VideoStreamManager
   - `src/styles/main.css` - 添加视频流相关样式

### UI设计要求

1. **卡片布局**
   - 在首页的dashboard-grid中添加新的视频流卡片
   - 卡片应该占据合适的空间，建议使用full-width类

2. **控制界面**
   - 视频显示区域
   - 机位切换按钮组
   - 播放/暂停按钮
   - 状态指示器

3. **响应式设计**
   - 确保在不同屏幕尺寸下正常显示
   - 视频比例保持合适

## 验收标准

1. 用户可以在首页看到视频流卡片
2. 点击播放按钮后能够看到摄像头的实时画面
3. 可以在两个摄像头之间切换（如果设备支持）
4. 可以暂停和恢复视频流
5. 界面美观，符合整体设计风格
6. 错误情况有适当的提示信息
